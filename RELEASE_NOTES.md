# 0.6.9

- Hotspot button works on One UI 9 again: when Samsung's own hotspot call is silently ignored, Android's tethering service is used instead.
- Fullscreen: the bottom-right corner no longer opens the Dashboard.
- Notifications menu: a tap above it closes it; the tap or swipe that closed it can no longer reopen it; taps land while it is still opening instead of restarting it.
- Notifications menu restyled after SHELL: rounded cards that rise in one after another, round icons that spin in, the app name swept in by its colour, the message typed out.
