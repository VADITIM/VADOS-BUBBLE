Service checking

The bubble runs as an accessibility service: that is the only window an ordinary app can put above the status bar, which is what makes the whole bubble tappable. Android starts and stops it with the toggle — there is nothing to start from here.

Replay

Each button replays that app's most recent real notification, image and all. If nothing has arrived from it yet, a stand-in with its colours is sent instead.

With system pop-ups suppressed the bubble is the only thing that announces a notification — it still lands in the shade, nothing is dropped. Needs Shizuku: the switch is a global setting no sideloaded app may write.

Shizuku powers the microphone-access toggle on the pill. It has to be started after every reboot, from the Shizuku app.

A toggle greyed out as Restricted setting means Android is blocking a sideloaded app. Open App info, use the three-dot menu, choose Allow restricted settings, then grant it again.
