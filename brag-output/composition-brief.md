# Hyperframes Composition Brief: Dynamic Bubble

## Objective
Create a short launch-style brag video for Dynamic Bubble, a One UI system overhaul.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: landscape — 1920x1080, 30fps
- Duration: 22 seconds

## Source Material
- Project root: VADOS-BUBBLE
- Primary files read: README.md, app/src/main/assets/dna.css, pill.css, pill.html, js/liquid.js
- Product name: Dynamic Bubble
- Tagline / strongest claim: "A system overhaul for One UI." / "Nothing appears from nowhere."
- Key UI to recreate: the pill at the cutout (black, 1px #262626 hairline, round), media mod (art + 3 bars), timer satellite, 300×155dp alert with app-accent border, the goo merge filter.
- Copy that must appear verbatim:
  - A system overhaul for One UI.
  - Nothing appears from nowhere.
  - A phone that feels alive, not one that feels decorated.

## Creative Direction
- Tone preset: polished
- Creative direction: quiet premium system film
- Interpretation: few words, long holds; motion arrives slowly and diagonally and leaves fast; the bubble is one continuous object across the whole film.
- Angle: One UI answers every event with its own piece of interface; Dynamic Bubble answers with one. The film performs the fold.
- Hook: stock chips and a heads-up card crowd the status bar, then drain into the cutout as liquid.
- Outro / punchline: "A phone that feels alive, not one that feels decorated." → DYNAMIC BUBBLE.
- Avoid: generic SaaS language, abstract filler, restyling the product away from V/AS.

## Visual Identity
- Background: #181818; phone screen #0e0e0e
- Text: rgba(255,255,255,0.87); labels #8a8a8a
- Accent: #5bfd5b
- Display font: Clash Display (local OTF from the project)
- Body font: Space Mono (local TTF from the project)
- Visual references: V/AS micro-labels (uppercase mono, wide tracking), hairline panels, bar-sweep reveal from dna.css.

## Storyboard

3. The row, and a message — 8.95s — satellite split 8.96, alert grows 12.65, swipe up.
4. Outro — 4.1s — closing line 17.91, name card.

## Audio
- Audio role: cinematic support, restrained
- Music: assets/music/happy-beats-business-moves-vol-11-by-ende-dot-app.mp3, fade out last 1.5s
